Simple Task Manager

概要
本プロジェクトは、HTML・CSS・JavaScriptを用いて作成したシンプルなタスク管理アプリです。

ユーザーはタスクの追加、完了状態の切り替え、削除を行うことができます。

主な機能
- タスク追加
- タスク削除
- タスク完了機能
- タスクフィルター機能（All / Active / Completed）
- localStorageによるデータ保存
- レスポンシブ対応

使用技術
- HTML
- CSS
- JavaScript

制作背景・目的
フロントエンド開発の基礎を学ぶことを目的として制作しました。
また、学生生活の中で日々のタスクを簡単に管理できる、実用的なアプリを作りたいと考え開発しました。

特に、
- JavaScriptによる画面の動的更新
- イベント処理
- 配列データの管理
- localStorageによるデータ保持

について理解を深めることを意識しました。

工夫した点
- シンプルで見やすいUI設計
- モバイル環境でも使用しやすいレスポンシブデザイン
- ページを再読み込みしてもタスクが保持される点

今後の改善案
- ドラッグ＆ドロップによる並び替え
- バックエンド・データベース連携
